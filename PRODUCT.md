## Platform

web

## Stack

delegated: React 19 + TypeScript + Vite + Three.js / React Three Fiber + GSAP (ScrollTrigger) — selected per brief authorization ("selecciona la mejor arquitectura compatible con GitHub Pages. Puedes utilizar React, Vite, TypeScript u otras tecnologías si realmente aportan valor") to deliver real-time WebGL 3D materials, custom shaders, scroll-linked choreography, code-splitting, and static GitHub Pages output.

## Users

Creative directors, technical hiring leads, studio founders, and prospective clients evaluating THORAL's creative engineering, design sensibility, interactive 3D mastery, and frontend craft on desktop, tablet, and mobile devices. (inferred from brief)

## Product Purpose

Personal digital portfolio and interactive showcase for the brand THORAL (`https://Thoraal.github.io/`), presenting identity, conceptual/demonstrative selected works, configurable areas of expertise, and direct contact channels through an immersive 3D editorial experience.

## Positioning

An authored interactive studio piece rather than a template portfolio: spatial WebGL industrial sculpture, architectural dark-plane editorial composition, and tactile motion engineering working as a single cohesive artifact from the first viewport.

## Operating Context

Hosted statically on GitHub Pages (`Thoraal/Thoraal.github.io`) with automated GitHub Actions deployment. Evaluated across 4K/ultrawide monitors down to 320px compact mobile screens, touch and pointer inputs, keyboard navigation, and `prefers-reduced-motion` environments.

## Capabilities and Constraints

- Must not fabricate biographical facts, employers, certifications, client names, email addresses, or social profiles; all personal metadata, expertise entries, and contact endpoints live in a clean central configuration with explicit provisional/conceptual labels where user data is pending.
- Zero emojis anywhere in UI or source; 100% custom geometric SVGs and consistent stroke iconography (Lucide).
- Real WebGL / Three.js 3D centerpiece with graceful non-WebGL / low-power fallback and `prefers-reduced-motion` support.

## Brand Commitments

- Brand name: **THORAL** with a bespoke geometric SVG emblem and custom typographic mark.
- Pinned visual direction from user reference (`Blvck Tumbler` / `LUMIER DARK`): Dark luxury + Futuristic editorial + 3D interactive experience — matte obsidian and smoked-slate split architectural planes, sandblasted matte-black 3D industrial form with realistic studio rim lighting, restrained vivid signal-orange / burnt-copper accents (`#E85D24`), warm bone/ivory display typography contrasted against hairline uppercase and recessed tonal background watermarks.

## Evidence on Hand

- Reference art direction board provided by user (`Blvck Tumbler` and `LUMIER DARK` compositions).
- Absent facts that must not be fabricated: personal biography details, commercial client roster, certifications, personal email, and social URLs (represented via clearly marked provisional/configurable entries).

## Product Principles

1. **The Artifact Leads:** Every viewport demonstrates craft directly through spatial depth, lighting, and typographic tension rather than claiming competence in prose.
2. **Restrained Industrial Luxury:** Darkness has material texture and architectural planes; signal orange appears only as a surgical focal accent, never indiscriminate glow.
3. **Honest Configurability:** Conceptual demonstrations and provisional personal fields are labeled transparently and centralized for effortless customization.
4. **Universal Precision:** Mobile, tablet, keyboard, and reduced-motion paths receive purpose-built layouts and interaction states with zero horizontal overflow.
